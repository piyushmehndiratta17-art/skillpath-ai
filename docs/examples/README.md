# SkillPath AI: Documented JSON Examples & Schema Guide

This directory provides concrete, schema-validated JSON fixtures demonstrating payloads used across the Assessment and Roadmap Engines.

---

## 📁 Files Overview

| File | Purpose | Corresponding TypeScript Interface |
|------|---------|------------------------------------|
| `questions.example.json` | Assessment questions across skills | `AssessmentQuestion[]` in `lib/assessment/types.ts` |
| `answers.example.json` | Student answer submissions | `AssessmentSubmission` in `lib/assessment/types.ts` |
| `results.example.json` | Assessment evaluation & scoring report | `AssessmentResult` in `lib/assessment/types.ts` |
| `roadmap.example.json` | Structured personalized roadmap | `PersonalizedRoadmapResult` in `lib/roadmap/types.ts` |
| `progress.example.json` | Learner progress state & metrics | `AppState` / `LearnerStats` in `lib/types.ts` |
| `recommendations.example.json` | Next-lesson recommendation payload | `NextLessonRecommendation` in `lib/roadmap/types.ts` |

## 1. Questions Schema (`questions.example.json`)
Each question contains:
- `id` (string): Unique identifier (e.g., `py-q1`, `js-q2`).
- `skill` (string): Core skill category (`javascript`, `python`, `java`, `dsa`).
- `topic` (string): Subtopic/domain (e.g., `Scope & Closures`, `Variables & Mutability`).
- `difficulty` (string): `'beginner'`, `'intermediate'`, or `'advanced'`.
- `prompt` (string): Question prompt displayed to user.
- `codeSnippet` (optional string): Formatted code block.
- `options` (array): 4 options, each with `id` (`a`, `b`, `c`, `d`) and `text`.
- `correctOptionId` (string): The correct choice identifier.
- `explanation` (string): Complete educational rationale explaining the correct answer and debunking distractors.
- `conceptTested` (string): Conceptual skill tested.

## 2. Answers Schema (`answers.example.json`)
Supports two client submission formats:
1. **Map Format**: `{ [questionId: string]: string | null }` (ideal for forms using key-value state).
2. **Array Format**: `Array<{ questionId: string, selectedOptionId: string | null }>` (ideal for step-by-step wizards).

Unanswered or skipped questions can be passed as `null` or omitted entirely; the engine safely records them as unattempted (0 points) without throwing.

## 3. Results Schema (`results.example.json`)
The output from `scoreAssessment(submission)` provides:
- `totalQuestions`, `attemptedCount`, `unansweredCount`, `correctCount`, `incorrectCount`
- `scorePercentage` (0 - 100)
- `estimatedProficiency`: `'beginner'` (<50%), `'intermediate'` (50-79%), `'advanced'` (>=80%)
- `weakTopics`: Array of topics where accuracy fell below the threshold (default 60%), sorted lowest score first.
- `strongTopics`: Topics mastered with >=80% accuracy.
- `topicBreakdown`: Detailed accuracy and status per topic (`mastered`, `proficient`, `needs_review`, `weak`).
- `detailedFeedback`: Per-question review with `isCorrect`, user's choice, correct choice, and explanation.

## 4. Roadmap Schema (`roadmap.example.json`)
The output from `generatePersonalizedRoadmap(input)`:
- `roadmap`: 100% compatible with Member 1's existing `Roadmap` and `Milestone` types (`app/dashboard`).
- `extendedMilestones`: Includes prerequisites (`prerequisites: string[]`), milestone learning objectives, hands-on practice tasks with starter code and hints, and end-of-module checkpoint quizzes.
- `weakTopicsTargeted`: Tracks which weak topics from the assessment were automatically reinforced in the curriculum.

## 5. Next Lesson Recommendations (`recommendations.example.json`)
Generated by `getRecommendedNextLesson(roadmap, { extendedMilestones, weakTopics })`:
- Identifies the next logical lesson.
- Flags whether the lesson targets an identified weak topic (`isWeakTopicReinforcement: true`).
- Provides a contextual user-friendly `reason` to display on the learner's dashboard banner.
